JevDex ranks results with a decision model. Laya runs entirely in this browser (nothing you type leaves the page). Switch to the remote Jev API under Settings if you have a key.
Settings

Not loaded. The weights are fetched from Hugging Face once and cached by the browser.

On a search, JevDex retrieves a short candidate list by keyword and asks Laya (one Choice question, plus a Noul “is this a real topic?” check) to rank it. The whole index cannot be scored at once: Laya reads ~512 tokens of context.

Sends { state, model, questions } with Authorization: Bearer <key>.
